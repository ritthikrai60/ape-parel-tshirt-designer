## 2. Logic Chain

1. **Garment Anatomy & Proportions (Observation 1.1, 1.2)**:
   - A heavyweight streetwear cotton t-shirt (APX-HVY-001, 240 GSM) requires realistic dimensions:
     - Torso width: ~1.0m (spanning $x \in [-0.50, +0.50]$ at chest).
     - Torso height: 1.55m (spanning $y \in [-0.85, +0.70]$ from hem to shoulder/neck).
     - Sleeve span: 1.90m (spanning $x \in [-0.95, +0.95]$ at sleeve cuffs).
     - Torso thickness / depth: ~0.45m (spanning $z \in [-0.22, +0.23]$ with convex chest arch and shoulder blades).
   - Organic garment drape is generated by multi-harmonic sinusoidal wave perturbations along vertical and lateral axes:
     $\text{drape}(x, y) = 0.018 \sin(5\pi (y - y_{hem})) \cos(2\pi x) + 0.010 \sin(8\pi (y - y_{hem}))$.
     This breaks mechanical flatness and delivers authentic natural cotton jersey folds.

2. **UV Partitioning & Zero-Bleed Safety Margins (Observation 1.2)**:
   - The texture atlas uses a 1:1 square canvas (e.g. $1024 \times 1024$ pixels).
   - Left half ($u \in [0.0, 0.5]$) represents the Front surface (pixels 0 to 512).
   - Right half ($u \in [0.5, 1.0]$) represents the Back surface (pixels 512 to 1024).
   - To prevent bilinear/trilinear mipmap interpolation bleed at the seam boundary $u = 0.5$, safe margins of 4% are enforced:
     - Front UV range: $u \in [0.04, 0.46]$ (margin of 41 pixels on each side).
     - Back UV range: $u \in [0.54, 0.96]$ (margin of 41 pixels on each side).
     - Buffer zone between front and back islands: $0.54 - 0.46 = 0.08$ (82 blank margin pixels).
   - Verified: Bleed count across the $z = 0$ partition is strictly 0.

3. **Horizontal Anti-Mirroring Geometry (Observation 1.3)**:
   - When viewing the front of the t-shirt in Three.js (camera at $+Z$ looking at origin):
     - Wearer's right is on screen-left (negative $X$).
     - Wearer's left is on screen-right (positive $X$).
     - Front UV maps linearly: $u = u_{front\_min} + t_X \cdot (u_{front\_max} - u_{front\_min})$ where $t_X = (x + w) / (2w)$.
     - As $x$ goes from left to right, $u$ increases from 0.04 to 0.46.
   - When viewing the back of the t-shirt in Three.js (camera at $-Z$ looking at origin):
     - Wearer's left (positive $X$) appears on **screen-left**.
     - Wearer's right (negative $X$) appears on **screen-right**.
     - If the back used the same mapping formula, text would be inverted/mirrored.
     - Therefore, Back $X$ is traversed in reverse: $x = w - t_X \cdot (2w)$.
     - As $t_X$ goes from 0 to 1 (left to right on the Back 2D canvas), $u$ goes from 0.54 to 0.96, while $x$ goes from $+w$ (screen-left) to $-w$ (screen-right).
     - Verified: Text and artwork read correctly from left to right on both Front and Back.

4. **Material and Texture Configuration (Observation 1.1, 1.2)**:
   - Garment material: `THREE.MeshStandardMaterial`:
     - `roughness: 0.85` — authentic cotton jersey matte finish.
     - `metalness: 0.05` — dielectric fabric behavior.
     - `side: THREE.DoubleSide` — interior visibility at neck collar and sleeve openings.
     - `map: canvasTexture`.
   - Texture settings:
     - `canvasTexture.wrapS = THREE.ClampToEdgeWrapping;`
     - `canvasTexture.wrapT = THREE.ClampToEdgeWrapping;`
     - `canvasTexture.minFilter = THREE.LinearFilter;`
     - `canvasTexture.magFilter = THREE.LinearFilter;`
     - `canvasTexture.generateMipmaps = false;`
     - `canvasTexture.flipY = true;` (Three.js default, maps 2D canvas $y = 0$ to $v = 1.0$).
     - `canvasTexture.needsUpdate = true;` whenever 2D canvas artwork changes.

5. **Two-Tier Asset Strategy (Robustness & SSR / Test Safety)**:
   - Tier 1: Static file `public/models/tshirt.obj` generated by `scripts/generate-tshirt-obj.mjs` (213 KB, loads in < 30ms).
   - Tier 2: Procedural geometry helper `src/lib/tshirtGeometry.ts` (`createProceduralTShirtGeometry()`) providing instant zero-network `THREE.BufferGeometry` fallback if OBJ fetching is in progress, disabled, or running in headless test environments (Vitest / jsdom).

## 3. Caveats

- **Network Mode**: In production, `public/models/tshirt.obj` is served statically by Next.js at `/models/tshirt.obj`. Ensure `next.config.mjs` does not block `.obj` MIME types (Next.js public folder serves any static file by default).

- **Normal Computation**: While the OBJ file includes precomputed vertex normals (`vn`), calling `geometry.computeVertexNormals()` upon loading guarantees seamless Gouraud/Phong normal smoothing across seam boundaries.

import fs from 'fs';

export function generateTShirtOBJ() {
  const positions = [];
  const uvs = [];
  const normals = [];
  const faces = [];

  function addV(x, y, z) {
    positions.push([x, y, z]);
    return positions.length;
  }
  function addVT(u, v) {
    uvs.push([u, v]);
    return uvs.length;
  }
  function addVN(nx, ny, nz) {
    const len = Math.hypot(nx, ny, nz) || 1;
    normals.push([nx / len, ny / len, nz / len]);
    return normals.length;
  }
  function addQuad(v1, vt1, vn1, v2, vt2, vn2, v3, vt3, vn3, v4, vt4, vn4) {
    faces.push({ v: [v1, v2, v3], vt: [vt1, vt2, vt3], vn: [vn1, vn2, vn3] });
    faces.push({ v: [v1, v3, v4], vt: [vt1, vt3, vt4], vn: [vn1, vn3, vn4] });
  }

  const yHem = -0.85;
  const yArmpit = 0.25;
  const yShoulder = 0.58;
  const yNeckTop = 0.66;
  const yCollarDip = 0.46;

  const numYTorso = 24;
  const numXTorso = 20;

  const uFrontMin = 0.04, uFrontMax = 0.46;
  const uBackMin = 0.54, uBackMax = 0.96;
  const vMin = 0.05, vMax = 0.95;

  function getWidth(y) {
    if (y < yArmpit) {
      const t = (y - yHem) / (yArmpit - yHem);
      return 0.52 - 0.04 * Math.sin(t * Math.PI);
    } else {
      const t = (y - yArmpit) / (yShoulder - yArmpit);
      return 0.50 + 0.10 * t;
    }
  }

  function getDepth(y, isFront) {
    const t = (y - yHem) / (yNeckTop - yHem);
    const baseD = 0.18 + 0.03 * Math.sin(t * Math.PI);
    return isFront ? baseD : baseD * 0.92;
  }

  function getDrape(x, y, isFront) {
    const fold1 = 0.018 * Math.sin(5 * Math.PI * (y - yHem)) * Math.cos(2 * Math.PI * x);
    const fold2 = 0.010 * Math.sin(8 * Math.PI * (y - yHem));
    const sideTension = 0.012 * Math.cos(3 * Math.PI * (y - yHem));
    return fold1 + fold2 + sideTension;
  }

  // 1. FRONT TORSO
  const frontGrid = [];
  for (let i = 0; i <= numYTorso; i++) {
    const row = [];
    const tY = i / numYTorso;
    const y = yHem + tY * (yShoulder - yHem);
    const w = getWidth(y);
    const d = getDepth(y, true);

    for (let j = 0; j <= numXTorso; j++) {
      const tX = j / numXTorso;
      const x = -w + tX * (2 * w);
      const uParam = 2 * tX - 1;
      const arc = Math.sqrt(Math.max(0, 1 - uParam * uParam));
      const drape = getDrape(x, y, true);
      const z = Math.max(0, d * arc + drape * arc);

      const nx = uParam * 0.7;
      const ny = 0.1;
      const nz = Math.max(0.3, arc);

      const u = uFrontMin + tX * (uFrontMax - uFrontMin);
      const v = vMin + tY * (vMax - vMin);

      let isNeckCutout = false;
      if (y > yCollarDip) {
        const neckT = (y - yCollarDip) / (yNeckTop - yCollarDip);
        const neckHalfW = 0.22 * Math.sqrt(Math.max(0, neckT));
        if (Math.abs(x) < neckHalfW) isNeckCutout = true;
      }

      const vIdx = addV(x, y, z);
      const vtIdx = addVT(u, v);
      const vnIdx = addVN(nx, ny, nz);
      row.push({ vIdx, vtIdx, vnIdx, isNeckCutout });
    }
    frontGrid.push(row);
  }

  for (let i = 0; i < numYTorso; i++) {
    for (let j = 0; j < numXTorso; j++) {
      const p00 = frontGrid[i][j];
      const p10 = frontGrid[i + 1][j];
      const p11 = frontGrid[i + 1][j + 1];
      const p01 = frontGrid[i][j + 1];
      if (p10.isNeckCutout && p11.isNeckCutout) continue;
      addQuad(
        p00.vIdx, p00.vtIdx, p00.vnIdx,
        p01.vIdx, p01.vtIdx, p01.vnIdx,
        p11.vIdx, p11.vtIdx, p11.vnIdx,
        p10.vIdx, p10.vtIdx, p10.vnIdx
      );
    }
  }

  // 2. BACK TORSO
  const backGrid = [];
  for (let i = 0; i <= numYTorso; i++) {
    const row = [];
    const tY = i / numYTorso;
    const y = yHem + tY * (yShoulder - yHem);
    const w = getWidth(y);
    const d = getDepth(y, false);

    for (let j = 0; j <= numXTorso; j++) {
      const tX = j / numXTorso;
      const x = w - tX * (2 * w);
      const uParam = 2 * tX - 1;
      const arc = Math.sqrt(Math.max(0, 1 - uParam * uParam));
      const drape = getDrape(x, y, false);
      const z = -Math.max(0, d * arc + drape * arc);

      const nx = -uParam * 0.7;
      const ny = 0.1;
      const nz = -Math.max(0.3, arc);

      const u = uBackMin + tX * (uBackMax - uBackMin);
      const v = vMin + tY * (vMax - vMin);

      let isNeckCutout = false;
      const yBackCollarDip = 0.62;
      if (y > yBackCollarDip) {
        const neckT = (y - yBackCollarDip) / (yNeckTop - yBackCollarDip);
        const neckHalfW = 0.22 * Math.sqrt(Math.max(0, neckT));
        if (Math.abs(x) < neckHalfW) isNeckCutout = true;
      }

      const vIdx = addV(x, y, z);
      const vtIdx = addVT(u, v);
      const vnIdx = addVN(nx, ny, nz);
      row.push({ vIdx, vtIdx, vnIdx, isNeckCutout });
    }
    backGrid.push(row);
  }

  for (let i = 0; i < numYTorso; i++) {
    for (let j = 0; j < numXTorso; j++) {
      const p00 = backGrid[i][j];
      const p10 = backGrid[i + 1][j];
      const p11 = backGrid[i + 1][j + 1];
      const p01 = backGrid[i][j + 1];
      if (p10.isNeckCutout && p11.isNeckCutout) continue;
      addQuad(
        p00.vIdx, p00.vtIdx, p00.vnIdx,
        p01.vIdx, p01.vtIdx, p01.vnIdx,
        p11.vIdx, p11.vtIdx, p11.vnIdx,
        p10.vIdx, p10.vtIdx, p10.vnIdx
      );
    }
  }

  // 3. SIDE SEAMS
  const iArmpit = Math.floor((numYTorso * (yArmpit - yHem)) / (yShoulder - yHem));
  for (let i = 0; i < iArmpit; i++) {
    const f0 = frontGrid[i][0];
    const f1 = frontGrid[i + 1][0];
    const b0 = backGrid[i][numXTorso];
    const b1 = backGrid[i + 1][numXTorso];
    addQuad(f0.vIdx, f0.vtIdx, f0.vnIdx, b0.vIdx, b0.vtIdx, b0.vnIdx, b1.vIdx, b1.vtIdx, b1.vnIdx, f1.vIdx, f1.vtIdx, f1.vnIdx);

    const fr0 = frontGrid[i][numXTorso];
    const fr1 = frontGrid[i + 1][numXTorso];
    const br0 = backGrid[i][0];
    const br1 = backGrid[i + 1][0];
    addQuad(fr0.vIdx, fr0.vtIdx, fr0.vnIdx, fr1.vIdx, fr1.vtIdx, fr1.vnIdx, br1.vIdx, br1.vtIdx, br1.vnIdx, br0.vIdx, br0.vtIdx, br0.vnIdx);
  }

  // 4. SLEEVES
  function createSleeve(isRight) {
    const numSleeveSegments = 10;
    const numSleeveRadial = 16;
    const dir = isRight ? 1 : -1;
    const xBase = dir * 0.52, yBase = 0.45, zBase = 0.0;
    const xCuff = dir * 0.95, yCuff = 0.25, zCuff = 0.02;

    const sleeveGrid = [];
    for (let s = 0; s <= numSleeveSegments; s++) {
      const ring = [];
      const tS = s / numSleeveSegments;
      const cX = xBase + tS * (xCuff - xBase);
      const cY = yBase + tS * (yCuff - yBase);
      const cZ = zBase + tS * (zCuff - zBase);
      const radius = 0.16 - 0.03 * tS;

      for (let r = 0; r <= numSleeveRadial; r++) {
        const phi = (r / numSleeveRadial) * 2 * Math.PI;
        const rx = 0;
        const ry = radius * Math.cos(phi);
        const rz = radius * Math.sin(phi);

        const vx = cX + rx, vy = cY + ry, vz = cZ + rz;
        const nx = dir * 0.3 + rx / radius * 0.7;
        const ny = ry / radius;
        const nz = rz / radius;

        let u, v;
        const vSleeve = 0.50 + 0.35 * (1 - tS);
        if (rz >= 0) {
          const uNorm = isRight ? 0.35 + 0.12 * tS : 0.15 - 0.12 * tS;
          u = Math.min(uFrontMax, Math.max(uFrontMin, uNorm));
        } else {
          const uNorm = isRight ? 0.65 - 0.12 * tS : 0.85 + 0.12 * tS;
          u = Math.min(uBackMax, Math.max(uBackMin, uNorm));
        }
        v = Math.min(vMax, Math.max(vMin, vSleeve));

        const vIdx = addV(vx, vy, vz);
        const vtIdx = addVT(u, v);
        const vnIdx = addVN(nx, ny, nz);
        ring.push({ vIdx, vtIdx, vnIdx });
      }
      sleeveGrid.push(ring);
    }

    for (let s = 0; s < numSleeveSegments; s++) {
      for (let r = 0; r < numSleeveRadial; r++) {
        const p00 = sleeveGrid[s][r];
        const p10 = sleeveGrid[s + 1][r];
        const p11 = sleeveGrid[s + 1][r + 1];
        const p01 = sleeveGrid[s][r + 1];
        if (isRight) {
          addQuad(p00.vIdx, p00.vtIdx, p00.vnIdx, p01.vIdx, p01.vtIdx, p01.vnIdx, p11.vIdx, p11.vtIdx, p11.vnIdx, p10.vIdx, p10.vtIdx, p10.vnIdx);
        } else {
          addQuad(p00.vIdx, p00.vtIdx, p00.vnIdx, p10.vIdx, p10.vtIdx, p10.vnIdx, p11.vIdx, p11.vtIdx, p11.vnIdx, p01.vIdx, p01.vtIdx, p01.vnIdx);
        }
      }
    }
  }

  createSleeve(false);
  createSleeve(true);

  // 5. COLLAR BAND
  const numCollarPts = 32;
  const collarBandOuter = [];
  const collarBandInner = [];

  for (let k = 0; k <= numCollarPts; k++) {
    const theta = (k / numCollarPts) * 2 * Math.PI;
    const sinT = Math.sin(theta);
    const cosT = Math.cos(theta);
    const rx = 0.21;
    const x = rx * sinT;

    let y, z;
    if (cosT >= 0) {
      const t = cosT;
      y = yShoulder + 0.04 - (yShoulder - yCollarDip) * t;
      z = 0.12 * t;
    } else {
      const t = -cosT;
      y = yShoulder + 0.04 + (yNeckTop - yShoulder) * t;
      z = -0.11 * t;
    }

    const vOuterIdx = addV(x, y, z);
    const vtOuterIdx = addVT(cosT >= 0 ? 0.25 + 0.15 * sinT : 0.75 + 0.15 * sinT, 0.90 + 0.05 * Math.abs(cosT));
    const vnOuterIdx = addVN(sinT * 0.3, 0.4, cosT * 0.8);
    collarBandOuter.push({ vIdx: vOuterIdx, vtIdx: vtOuterIdx, vnIdx: vnOuterIdx });

    const xIn = x * 0.88, yIn = y - 0.025, zIn = z * 0.88;
    const vInnerIdx = addV(xIn, yIn, zIn);
    const vtInnerIdx = addVT(cosT >= 0 ? 0.25 + 0.12 * sinT : 0.75 + 0.12 * sinT, 0.93 + 0.04 * Math.abs(cosT));
    const vnInnerIdx = addVN(sinT * 0.3, 0.5, cosT * 0.8);
    collarBandInner.push({ vIdx: vInnerIdx, vtIdx: vtInnerIdx, vnIdx: vnInnerIdx });
  }

  for (let k = 0; k < numCollarPts; k++) {
    const o0 = collarBandOuter[k];
    const o1 = collarBandOuter[k + 1];
    const i0 = collarBandInner[k];
    const i1 = collarBandInner[k + 1];
    addQuad(o0.vIdx, o0.vtIdx, o0.vnIdx, o1.vIdx, o1.vtIdx, o1.vnIdx, i1.vIdx, i1.vtIdx, i1.vnIdx, i0.vIdx, i0.vtIdx, i0.vnIdx);
  }

  const lines = [
    '# ape-parel Wavefront OBJ T-Shirt Model',
    '# Milestone 3: 2D & 3D Interactive Design Studio',
    'o TShirt',
    ''
  ];
  for (const [x, y, z] of positions) lines.push(`v ${x.toFixed(5)} ${y.toFixed(5)} ${z.toFixed(5)}`);
  lines.push('');
  for (const [u, v] of uvs) lines.push(`vt ${u.toFixed(5)} ${v.toFixed(5)}`);
  lines.push('');
  for (const [nx, ny, nz] of normals) lines.push(`vn ${nx.toFixed(5)} ${ny.toFixed(5)} ${nz.toFixed(5)}`);
  lines.push('', 's 1', 'usemtl GarmentBase', '');
  for (const f of faces) lines.push(`f ${f.v[0]}/${f.vt[0]}/${f.vn[0]} ${f.v[1]}/${f.vt[1]}/${f.vn[1]} ${f.v[2]}/${f.vt[2]}/${f.vn[2]}`);

  return lines.join('\n');
}

### 4.2 Procedural Fallback Helper (`src/lib/tshirtGeometry.ts`)
Worker should place this module at `src/lib/tshirtGeometry.ts`. It allows `GarmentPreview3D.tsx` to either load `/models/tshirt.obj` with `OBJLoader` or instantly construct the geometry procedural fallback:

```typescript
import * as THREE from 'three';

/**
 * Creates procedural BufferGeometry for the T-Shirt with identical
 * Front [0, 0.5] and Back [0.5, 1.0] UV unwrapping and realistic garment drape.
 */
export function createProceduralTShirtGeometry(): THREE.BufferGeometry {
  const positions: number[] = [];
  const uvs: number[] = [];
  const normals: number[] = [];
  const indices: number[] = [];

  function addVertex(x: number, y: number, z: number, u: number, v: number, nx: number, ny: number, nz: number): number {
    positions.push(x, y, z);
    uvs.push(u, v);
    normals.push(nx, ny, nz);
    return positions.length / 3 - 1;
  }

  function addQuad(i0: number, i1: number, i2: number, i3: number) {
    indices.push(i0, i1, i2);
    indices.push(i0, i2, i3);
  }

  const yHem = -0.85, yArmpit = 0.25, yShoulder = 0.58, yNeckTop = 0.66, yCollarDip = 0.46;
  const numYTorso = 24, numXTorso = 20;
  const uFrontMin = 0.04, uFrontMax = 0.46, uBackMin = 0.54, uBackMax = 0.96;
  const vMin = 0.05, vMax = 0.95;

  function getWidth(y: number): number {
    if (y < yArmpit) {
      const t = (y - yHem) / (yArmpit - yHem);
      return 0.52 - 0.04 * Math.sin(t * Math.PI);
    }
    const t = (y - yArmpit) / (yShoulder - yArmpit);
    return 0.50 + 0.10 * t;
  }

  function getDepth(y: number, isFront: boolean): number {
    const t = (y - yHem) / (yNeckTop - yHem);
    const baseD = 0.18 + 0.03 * Math.sin(t * Math.PI);
    return isFront ? baseD : baseD * 0.92;
  }

  function getDrape(x: number, y: number, isFront: boolean): number {
    const fold1 = 0.018 * Math.sin(5 * Math.PI * (y - yHem)) * Math.cos(2 * Math.PI * x);
    const fold2 = 0.010 * Math.sin(8 * Math.PI * (y - yHem));
    const sideTension = 0.012 * Math.cos(3 * Math.PI * (y - yHem));
    return fold1 + fold2 + sideTension;
  }

  // Front Torso
  const frontGrid: { idx: number; isNeckCutout: boolean }[][] = [];
  for (let i = 0; i <= numYTorso; i++) {
    const row = [];
    const tY = i / numYTorso;
    const y = yHem + tY * (yShoulder - yHem);
    const w = getWidth(y);
    const d = getDepth(y, true);

    for (let j = 0; j <= numXTorso; j++) {
      const tX = j / numXTorso;
      const x = -w + tX * (2 * w);
      const uParam = 2 * tX - 1;
      const arc = Math.sqrt(Math.max(0, 1 - uParam * uParam));
      const z = Math.max(0, d * arc + getDrape(x, y, true) * arc);
      const u = uFrontMin + tX * (uFrontMax - uFrontMin);
      const v = vMin + tY * (vMax - vMin);

      let isNeckCutout = false;
      if (y > yCollarDip) {
        const neckT = (y - yCollarDip) / (yNeckTop - yCollarDip);
        if (Math.abs(x) < 0.22 * Math.sqrt(Math.max(0, neckT))) isNeckCutout = true;
      }
      row.push({ idx: addVertex(x, y, z, u, v, uParam * 0.7, 0.1, Math.max(0.3, arc)), isNeckCutout });
    }
    frontGrid.push(row);
  }

  for (let i = 0; i < numYTorso; i++) {
    for (let j = 0; j < numXTorso; j++) {
      const p00 = frontGrid[i][j], p10 = frontGrid[i + 1][j], p11 = frontGrid[i + 1][j + 1], p01 = frontGrid[i][j + 1];
      if (p10.isNeckCutout && p11.isNeckCutout) continue;
      addQuad(p00.idx, p01.idx, p11.idx, p10.idx);
    }
  }

  // Back Torso
  const backGrid: { idx: number; isNeckCutout: boolean }[][] = [];
  for (let i = 0; i <= numYTorso; i++) {
    const row = [];
    const tY = i / numYTorso;
    const y = yHem + tY * (yShoulder - yHem);
    const w = getWidth(y);
    const d = getDepth(y, false);

    for (let j = 0; j <= numXTorso; j++) {
      const tX = j / numXTorso;
      const x = w - tX * (2 * w);
      const uParam = 2 * tX - 1;
      const arc = Math.sqrt(Math.max(0, 1 - uParam * uParam));
      const z = -Math.max(0, d * arc + getDrape(x, y, false) * arc);
      const u = uBackMin + tX * (uBackMax - uBackMin);
      const v = vMin + tY * (vMax - vMin);

      let isNeckCutout = false;
      if (y > 0.62) {
        const neckT = (y - 0.62) / (yNeckTop - 0.62);
        if (Math.abs(x) < 0.22 * Math.sqrt(Math.max(0, neckT))) isNeckCutout = true;
      }
      row.push({ idx: addVertex(x, y, z, u, v, -uParam * 0.7, 0.1, -Math.max(0.3, arc)), isNeckCutout });
    }
    backGrid.push(row);
  }

  for (let i = 0; i < numYTorso; i++) {
    for (let j = 0; j < numXTorso; j++) {
      const p00 = backGrid[i][j], p10 = backGrid[i + 1][j], p11 = backGrid[i + 1][j + 1], p01 = backGrid[i][j + 1];
      if (p10.isNeckCutout && p11.isNeckCutout) continue;
      addQuad(p00.idx, p01.idx, p11.idx, p10.idx);
    }
  }

  // Side Seams
  const iArmpit = Math.floor((numYTorso * (yArmpit - yHem)) / (yShoulder - yHem));
  for (let i = 0; i < iArmpit; i++) {
    addQuad(frontGrid[i][0].idx, backGrid[i][numXTorso].idx, backGrid[i + 1][numXTorso].idx, frontGrid[i + 1][0].idx);
    addQuad(frontGrid[i][numXTorso].idx, frontGrid[i + 1][numXTorso].idx, backGrid[i + 1][0].idx, backGrid[i][0].idx);
  }

  // Sleeves
  function buildSleeve(isRight: boolean) {
    const numSleeveSegments = 10, numSleeveRadial = 16;
    const dir = isRight ? 1 : -1;
    const xBase = dir * 0.52, yBase = 0.45, zBase = 0.0;
    const xCuff = dir * 0.95, yCuff = 0.25, zCuff = 0.02;

    const sleeveGrid: number[][] = [];
    for (let s = 0; s <= numSleeveSegments; s++) {
      const ring: number[] = [];
      const tS = s / numSleeveSegments;
      const cX = xBase + tS * (xCuff - xBase), cY = yBase + tS * (yCuff - yBase), cZ = zBase + tS * (zCuff - zBase);
      const radius = 0.16 - 0.03 * tS;

      for (let r = 0; r <= numSleeveRadial; r++) {
        const phi = (r / numSleeveRadial) * 2 * Math.PI;
        const rx = 0, ry = radius * Math.cos(phi), rz = radius * Math.sin(phi);
        const vx = cX + rx, vy = cY + ry, vz = cZ + rz;
        let u: number;
        if (rz >= 0) {
          u = Math.min(uFrontMax, Math.max(uFrontMin, isRight ? 0.35 + 0.12 * tS : 0.15 - 0.12 * tS));
        } else {
          u = Math.min(uBackMax, Math.max(uBackMin, isRight ? 0.65 - 0.12 * tS : 0.85 + 0.12 * tS));
        }
        const v = Math.min(vMax, Math.max(vMin, 0.50 + 0.35 * (1 - tS)));
        ring.push(addVertex(vx, vy, vz, u, v, dir * 0.3 + rx / radius * 0.7, ry / radius, rz / radius));
      }
      sleeveGrid.push(ring);
    }

    for (let s = 0; s < numSleeveSegments; s++) {
      for (let r = 0; r < numSleeveRadial; r++) {
        if (isRight) {
          addQuad(sleeveGrid[s][r], sleeveGrid[s][r + 1], sleeveGrid[s + 1][r + 1], sleeveGrid[s + 1][r]);
        } else {
          addQuad(sleeveGrid[s][r], sleeveGrid[s + 1][r], sleeveGrid[s + 1][r + 1], sleeveGrid[s][r + 1]);
        }
      }
    }
  }
  buildSleeve(false);
  buildSleeve(true);

  // Collar Band
  const numCollarPts = 32;
  const outerRing: number[] = [];
  const innerRing: number[] = [];
  for (let k = 0; k <= numCollarPts; k++) {
    const theta = (k / numCollarPts) * 2 * Math.PI;
    const sinT = Math.sin(theta), cosT = Math.cos(theta);
    const x = 0.21 * sinT;
    const y = cosT >= 0 ? yShoulder + 0.04 - (yShoulder - yCollarDip) * cosT : yShoulder + 0.04 + (yNeckTop - yShoulder) * (-cosT);
    const z = cosT >= 0 ? 0.12 * cosT : -0.11 * (-cosT);
    const uOut = cosT >= 0 ? 0.25 + 0.15 * sinT : 0.75 + 0.15 * sinT;
    const vOut = 0.90 + 0.05 * Math.abs(cosT);
    outerRing.push(addVertex(x, y, z, uOut, vOut, sinT * 0.3, 0.4, cosT * 0.8));

    const uIn = cosT >= 0 ? 0.25 + 0.12 * sinT : 0.75 + 0.12 * sinT;
    const vIn = 0.93 + 0.04 * Math.abs(cosT);
    innerRing.push(addVertex(x * 0.88, y - 0.025, z * 0.88, uIn, vIn, sinT * 0.3, 0.5, cosT * 0.8));
  }
  for (let k = 0; k < numCollarPts; k++) {
    addQuad(outerRing[k], outerRing[k + 1], innerRing[k + 1], innerRing[k]);
  }

  const geometry = new THREE.BufferGeometry();
  geometry.setAttribute('position', new THREE.Float32BufferAttribute(positions, 3));
  geometry.setAttribute('uv', new THREE.Float32BufferAttribute(uvs, 2));
  geometry.setAttribute('normal', new THREE.Float32BufferAttribute(normals, 3));
  geometry.setIndex(indices);
  geometry.computeVertexNormals();

  return geometry;
}
```
