# Definition of Done (DoD)

A task or feature is considered "Done" only when:

1. **Code Completeness**
   - Acceptance criteria are fully met.
   - Code builds/compiles without errors.
   - No dead code, debug statements, or hardcoded secrets left behind.

2. **Testing**
   - Unit tests are written and pass.
   - Integration tests are written and pass (if applicable).
   - Code coverage is not reduced.

3. **Code Quality**
   - Code passes linting and formatting rules.
   - Code has been reviewed by an independent reviewer (Agent or Human).

4. **Documentation**
   - Code is adequately commented.
   - External documentation (e.g., API specs, README) is updated.

5. **Security & Deployment**
   - Dependency vulnerability checks pass.
   - Required migrations are documented and tested.
   - Rollback plan is verified.
